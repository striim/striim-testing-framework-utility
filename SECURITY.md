# Security policy

Report suspected security vulnerabilities privately through this repository's **Security** tab,
using **Report a vulnerability**. Never report vulnerabilities in public issues.

Include the affected version or commit, the potential impact, steps to reproduce the problem,
and a minimal example or relevant logs. Remove credentials, license keys and private data
before sharing any material.

Ordinary bugs and feature requests belong in this repository's issues. See
[CONTRIBUTING.md](CONTRIBUTING.md) for what to include.
