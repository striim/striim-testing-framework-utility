# TQL guides

How to write, tune and review Striim TQL applications. Read only the page your task needs.

| Task | Read |
|---|---|
| Write a new application | [AUTHORING.md](AUTHORING.md), then the closest example in [PATTERNS.md](PATTERNS.md) |
| Look up syntax, a function or a writer's mapping | [REFERENCE.md](REFERENCE.md) |
| Make an application faster or simpler | [RULES.md](RULES.md) |
| Review or fix someone's TQL | [REVIEW.md](REVIEW.md) |
| Test the application with this framework | [WRITING-TESTS.md](../WRITING-TESTS.md) |

The pages cover Striim 5.4. Adapter properties not covered here are on each adapter's page at
[docs.striim.com](https://www.striim.com/docs/platform/en/).
